# Real-Life Side Quest Generator

An immersive, RPG-inspired web app that transforms everyday life into interactive side quests. Generate dynamic real-world challenges, earn XP, level up, and track streaks — all inside a sleek, animated interface.

---

## Features

- 🎯 Dynamic quest generation (Objective + Location + Bonus Twist)
- 📈 XP system with leveling mechanics
- 🔥 Streak tracking system
- ⚔️ Difficulty modes (Normal, Hard, Extreme)
- 🎨 Animated UI using Framer Motion
- 💎 Clean, modern design with Tailwind CSS
- 🏆 Reward scaling based on difficulty

---

## Concept

This project gamifies personal growth by turning ordinary actions into RPG-style missions. Instead of grinding in a game, you level up in real life.

Extreme Mode increases XP rewards for higher-risk, higher-growth challenges.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/real-life-side-quest.git
cd real-life-side-quest
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

---

## How It Works

1. Click **Generate Quest**
2. Complete the real-world objective
3. Press **Complete Quest**
4. Earn XP and increase your streak
5. Level up every 50 XP

### XP Scaling

- Normal → Base XP  
- Hard → 2x XP  
- Extreme → 3x XP
